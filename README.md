## 📱 What is react-native-showtime?

react-native-showtime is an app that helps you see where you tap and swipe on your iPhone screen. It shows small marks for each tap or gesture you make. This is useful when you want to demonstrate how you use an app or teach others to use touch controls on iOS devices.

This tool is designed to work with React Native apps on iOS, but this guide will help you get it running on a Windows computer so you can start using it.

---

## 🖥️ System Requirements

Before you begin, make sure your setup matches these needs:

- **Operating System**: Windows 10 or later.
- **iPhone or iPad**: Running iOS 10 or newer.
- **USB Cable**: To connect your device to your Windows PC.
- **iTunes installed on Windows**: This helps your computer recognize the iPhone or iPad.
- **A React Native app installed on the iOS device**: This app will use react-native-showtime to display taps.

## 💡 How react-native-showtime Works

The app captures touch events from the connected iOS device and displays visual dots or highlights for taps and swipes in real-time. This helps in situations like:

- Recording tutorials showing how to use an app.
- Giving presentations with clear visual feedback of touch input.
- Testing app gestures with visible confirmation.

## ⚙️ Configuration and Settings

react-native-showtime offers options to adjust how touches appear on your screen:

- **Dot Size**: Change the size of the tap marker.
- **Color**: Pick a color for the tap highlights to improve visibility.
- **Fade Time**: Set how long the taps stay on screen before disappearing.
- **Gesture Types**: Choose if you want to see taps only or swipes and other gestures too.

You can access these settings inside the app or via a preferences file, depending on the version.
